## 🚀 How to Install TubeLense

### Step 1: Download the ZIP File
- Open this GitHub repository.
- Click the green **Code** button.
- Select **Download ZIP**.

### Step 2: Extract the ZIP File
- Locate the downloaded `.zip` file.
- Right-click it and select **Extract All** (Windows) or use an extraction tool.
- Make sure the `tubelense_extension` folder is accessible.

### Step 3: Enable Developer Mode
- Open Chrome and navigate to `chrome://extensions/`.
- Turn on **Developer mode** in the top-right corner.
- Click **Load unpacked**.

### Step 4: Select the Extension Folder
- Navigate to the extracted files.
- Select the **`tubelense_extension`** folder and click **Select Folder**.

🎉 **That's it!** TubeLense is now installed and ready to use.

Note: you can delete the "extension" and "website" folder, that's anyway useless if you don't want to view the raw code.
